# The Sports Business Library — powered by Ballketing

## What this is
A web application that lets anyone search and explore a curated library of 400+ enriched sports business resources (podcasts, articles, books, reports), AND ask natural language questions that get answered using the library as the knowledge source. Built by Jaime Domínguez Pérez de Ayala, founder of Ballketing.

## Why it exists
Jaime has spent over a decade curating knowledge from across the sports industry. Every entry has been enriched with structured summaries including Key Themes, Main Insights, Frameworks & Concepts, Notable Quotes, and Action Items. This tool makes that knowledge accessible to anyone working in the sports business.

## Technical principles

- Quality over speed. Every design decision should favor craft and polish
- Mobile-first responsive design
- Fast load times — this should feel instant
- Accessible markup throughout
- Clean, premium visual design. This represents Ballketing's brand
- When in doubt, keep it simple
